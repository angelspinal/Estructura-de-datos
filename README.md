## Descripción

Este repositorio contiene diferentes trabajos, ejercicios y proyectos desarrollados durante la carrera de Ingeniería de Sistemas.

Los archivos están organizados de acuerdo con las actividades realizadas en clase, incluyendo ejercicios de programación, estructuras de datos, recursividad y proyectos prácticos.

El objetivo principal es almacenar y documentar el aprendizaje adquirido mediante la implementación de soluciones en Python.

## Proyectos incluidos

### Mini Proyecto 1 - ClinicLog

ClinicLog es un sistema de consola para registrar pacientes, asociar tratamientos y llevar un seguimiento básico mediante observaciones de tomas, visitas o controles.

Entre sus principales funciones se encuentran:

- Registrar pacientes.
- Registrar tratamientos asociados a un paciente.
- Consultar pacientes y tratamientos.
- Registrar seguimientos.
- Validar los datos ingresados.
- Controlar opciones y entradas inválidas.

### Mini Proyecto 2 - ClinicLog

Segunda versión o avance del proyecto ClinicLog, acompañado de archivos de código fuente, documentación y un notebook de Jupyter.
